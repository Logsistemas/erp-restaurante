# Sistema de Estoque Restaurante — PEPS + CMV

Versão com painel de CMV mensal e meta de 36%.

## Como rodar

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Se já tiver banco da versão anterior, copie o arquivo `estoque_restaurante.db` para esta pasta antes de rodar.
